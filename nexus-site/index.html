NEXUS Robotics is the robotics team of K J Somaiya School of Engineering, Mumbai. Every year the ABU Robocon problem lands — and every year we answer it with a machine designed, machined, wired and programmed in-house.

No bought designs. No outsourced builds. Thirty-eight students, five divisions, one workshop in Vidyavihar — and a fifteen-year record of machines that run when the arena lights come on.

06 / THE SYSTEM FIVE DIVISIONS · ONE MACHINE
01 MECHANICAL CAD · MACHINING · DRIVETRAIN ↗ Engineering the physical systems that transform design into movement — frames, drivetrains and mechanisms machined to run under arena load. SYS/01 — LOAD PATH: WHEEL > SHAFT > GEARBOX > FRAME 02 ELECTRONICS POWER · PCB · SENSING ↗ Power and sensing — PCB design, battery systems and the nervous system that keeps every actuator and processor alive. SYS/02 — POWER BUDGET: 24V BUS / 5V LOGIC / 3.3V RADIO 03 EMBEDDED CODING FIRMWARE · CONTROL · AUTONOMY ↗ Firmware, control loops and autonomy — the code that turns sensors into decisions and motors into motion. SYS/03 — CONTROL LOOP: 400 HZ PID / STATE MACHINE 04 AUTOMATION AUTONOMY · CONTROL · VISION ↗ Autonomy, control and perception — sensor fusion, path planning and closed-loop decision systems that let the machine think, navigate and act on its own. SYS/04 — AUTONOMY: SENSOR FUSION / PATH PLANNING / 400 HZ CONTROL 05 PR & MARKETING SPONSORS · OUTREACH · OPERATIONS ↗ Operations, sponsors and outreach — the division that funds the build and tells the story.
